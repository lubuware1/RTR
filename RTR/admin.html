⚙️ Matchweek Control
Fixture Sync

Pulls the latest Premier League fixtures from football-data.org and adds any missing matches automatically.

Incident Sync

Pulls yellow cards, red cards and penalties for completed matches in the active matchweek. Takes ~70 seconds due to API rate limits.

Forum — Create GW Match Posts

Creates one forum discussion post per fixture in the active matchweek. Skips any fixture that already has a post. Users can then reply to discuss the match and referee.

🏠 Homepage Content

Edit the headlines, text and images/videos shown on the homepage (index.html). For an image or video, paste a path to a file already in the images/images/video folder, or any external URL — there's no upload button yet.

📰 Articles (full story pages)

Full "click a headline, read the story" pages, served at article.html?id=…. Write one here, then paste its ID into a homepage card above (Article ID field) to link that card to it.
